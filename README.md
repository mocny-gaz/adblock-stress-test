# adblock-stress-test
a bunch of external filter lists (around 2400) to really stress test capabilities of an adblocker. also for when theres no efficient pasting ive made just a big file with all those rules
### only for stress testing purposes not actual usage
### i do not own any of the filter lists so follow their license

**HOW TO USE: paste those urls in as external filter list(s), or download and upload rules from a file, or just copy them and paste over as rules**
## external filter lists
https://github.com/mocny-gaz/adblock-stress-test/blob/main/external_urls.txt                                                                      
copy them from this file and paste as *external filter* lists **not** actual adblock rules
